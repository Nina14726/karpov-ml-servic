# Третья часть финального проекта

Улучшение рекомендательной системы из части 2 с использованием Deep Learning.

## Итоговая архитектура

- тексты постов векторизуются с помощью `distilbert-base-cased`;
- берётся `[CLS]`-представление из `last_hidden_state[:, 0, :]`;
- эмбеддинги размерности 768 сжимаются до 15 признаков через PCA;
- к DL-признакам добавляются признаки пользователя, темы поста, текста и времени;
- финальная модель — `CatBoostClassifier`;
- сервис — FastAPI endpoint `/post/recommendations/`.

Финальный bundle модели содержит и CatBoost, и заранее рассчитанные `post_features`, чтобы сервису не требовалась отдельная таблица с DL-признаками.

## Результат

Финальная версия части 3 успешно прошла проверку LMS: **Passed with 100%**.

При обучении на 1 000 000 взаимодействий:

- Train ROC-AUC: `0.7411`
- Test ROC-AUC: `0.6703`
- best iteration: `689`

Требование задания по Hitrate было выполнено при финальной LMS-проверке.

## Файлы

- `train_model.py` — получение DistilBERT-признаков, PCA, обучение CatBoost;
- `app.py` — сервис рекомендаций для bundle-модели;
- `load_data.py` — загрузка данных;
- `database.py` — подключение к PostgreSQL;
- `schema.py` — Pydantic-схемы;
- `requirements.txt` — зависимости.

Секреты и пароли в репозиторий не коммитятся; для локального запуска используются переменные окружения.
