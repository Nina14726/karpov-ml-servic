# Вторая часть финального проекта

Персонализированная рекомендательная система для ленты постов.

## Текущая структура

- `schema.py` — Pydantic-модели, перенесённые из первой части проекта.
- `database.py` — функция подключения к PostgreSQL.
- `requirements.txt` — зависимости, разрешённые в окружении LMS.

## Этапы работы

1. Выгрузить пользователей, посты и выборку взаимодействий из PostgreSQL.
2. Подготовить признаки пользователей, постов и временного контекста.
3. Сформировать обучающую выборку и разделить её на train/test.
4. Обучить модель и проверить качество.
5. Сохранить модель в pickle-файл.
6. Сохранить признаки пользователей и постов в PostgreSQL.
7. Подключить модель и признаки к FastAPI-сервису рекомендаций.

Код и файлы следующих этапов добавляются по мере выполнения точных заданий курса.
