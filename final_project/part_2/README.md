# Вторая часть финального проекта

Персонализированная рекомендательная система для ленты постов.

## Текущая структура

- `schema.py` — Pydantic-модели, перенесённые из первой части проекта.
- `database.py` — функция подключения к PostgreSQL.
- `requirements.txt` — зависимости, разрешённые в окружении LMS.
- `load_data.py` — выгрузка пользователей, постов и просмотров из PostgreSQL.

## Выполнено

### Выгрузка данных из БД

`load_data.py` загружает три датафрейма:

- пользователей из `public.user_data`;
- посты из `public.post_text_df`;
- просмотры из `public.feed_data` с заполненной целевой переменной `target`.

По умолчанию загружается 5 000 000 строк взаимодействий. Допустимый предел задания — 10 000 000 строк.

Запуск из папки `part_2`:

```bash
python load_data.py
```

Для уменьшенной проверочной выгрузки:

```bash
python load_data.py --feed-limit 10000
```

Скрипт проверяет наличие обязательных столбцов, отсутствие пропусков в `target`, тип действия `view` и ограничение на размер выборки.
